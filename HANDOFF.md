## 2. Где мы сейчас (главное)

> Ниже в этом разделе — история с Blender-фигурами (03.11), она больше не основной путь.

**Выбранное направление — мягкие «мармеладные» 3D-фигуры в Blender, как у французского аккаунта `les.zamours2`**
(средне 380 тыс. просмотров, топ 2,1 млн): она — розовая, он — синий, тёмно-синяя спальня/квартира, ночник,
размытый фон, субтитры обычным регистром, текст по формуле «смелое утверждение → «это называют <термин>» → как это
проявляется → тёплый/горький финал».

Пользователю **нравятся фигуры** из `blender_figures/` (лист персонажей `figures_front.jpg`, `figures_back.jpg`).
Утверждено пользователем:
- форма тела как в первой версии листа (`4d46243`), только **равномерно чуть плотнее** (радиусы ×1.16). Не менять плечи/шею/посадку головы без просьбы;
- у неё волосы **распущенные, чуть ниже плеч**, **без чёлки**, лоб и брови открыты, пробор по центру, волосы спереди **не лежат на плечах** — только сзади и по бокам;
- переход волос ко лбу должен быть **плавным, без бортика/ступеньки**;
- всё должно быть **гладенько**, без острых краёв.

**Свисающие волосы — решено (03.11):** одна цельная масса (деформированная сфера), голова и волосы слиты в одну поверхность (voxel remesh + сглаживание), маска «волосы/кожа» переносится с исходной головы, снаружи черепа — всегда волосы. Без швов, прядей и острых краёв; спереди не ложатся на плечи. Крупные планы: `blender_figures/hair_closeup.jpg`. Ниже — история попыток.

**Было (история): свисающие волосы.**
- Тонкая оболочка (shell + solidify) → края «острые/обрывистые» — не понравилось.
- Метаболлы (текущая версия в `blender_figures/figures.py`) → видно отдельные «макаронины» — **не понравилось**.
- Идея, которую не успели проверить: одна **сплошная толстая** оболочка (solidify ~0.06, subsurf 3, сглаженная кромка),
  выходящая из головы по касательной; или sculpt-подобная цельная форма. Без прядей и складок.
- Волосы на самой голове сделаны как часть головы (приподнятая область + плавный переход цвета по маске `hairmask`) —
  это решило «бортик» у лба, оставить.

После волос: поставить фигуры в сцены под конкретный сценарий (кровать — `blender_figures/bed_pair.py`, диван, кухня,
окно), затем ролик.

## 3. Как запускать

### Blender (основной путь)
```bash
mkdir -p /opt/blender && cd /opt/blender && curl -sSL https://download.blender.org/release/Blender4.2/blender-4.2.3-linux-x64.tar.xz | tar -xJ
B=/opt/blender/blender-4.2.3-linux-x64/blender
$B -b -P blender_figures/figures.py -- out/fig 24 0.5     # лист персонажей, превью 540x960 (~20 с на кадр без GPU)
$B -b -P blender_figures/figures.py -- out/fig 32 1.0     # полное качество 1080x1920 (~95 с на кадр без GPU)
$B -b -P blender_figures/bed_pair.py -- out/bed.png 32 1.0  # сцена в кровати (фигуры там старой версии)
```
- Фигуры: Skin modifier + Subdivision (тело), UV-сферы (голова, кисти, стопы), лицо — тонкие торы-дуги и эллипсоиды.
- Рендер Cycles на CPU. В облачной сессии без видеокарты ролик (≈2000 кадров) займёт сутки+; на ПК с GPU — порядка часа.
  Варианты: финальный рендер у пользователя на ПК с GPU, или облегчённый (меньше разрешение/кадров + движение камеры).

  `scenes.py` (диван, кухонный стол, кровать, парк; 17 кадров под текст), `videos/01_spiegel/compose.py` (сборка: движение
  камеры по стоп-кадрам, субтитры вверху, фортепиано).
- **Версия 1 собрана из стоп-кадров (облако без видеокарты) — пользователю НЕ понравилось: «нет эмоций, не взаимодействуют».**

### Что сделать на компьютере пользователя (есть видеокарта)
1. Рендер на GPU: в `scenes.py` → `sc.cycles.device = "GPU"` + включить CUDA/OptiX/Metal в preferences
   (`bpy.context.preferences.addons["cycles"].preferences.compute_device_type = "OPTIX"` и `get_devices()`).
2. **Настоящая анимация в каждой сцене (3–5 с, 30 fps)**: ключевые кадры поз через `figure(...)` нельзя (меш строится один раз),
   поэтому сделать риг: арматура с костями (позвоночник, шея, голова, плечо-локоть-кисть, бедро-колено) + Skin-модификатор →
   `Armature`-модификатор, либо строить фигуру из Skin и анимировать **вершины skin-меша** через shape keys / hooks
   (каждая точка сустава = hook-empty, анимируем empties). Hooks — самый простой путь: `P[joint]` → empty, keyframe на нём.
3. Взаимодействие по тексту: она кладёт голову ему на плечо (наклон + голова), он поворачивается к ней, оба тянутся к чашке
   и касаются руками, идут в ногу (шаги), держатся за руки, он отворачивается, она смотрит ему вслед.
4. Эмоции в кадре: моргание (глаза → дуги на 3 кадра), смена рта smile→flat→sad, брови вверх при грусти, лёгкое дыхание (грудь).
5. Камера — плавный наезд/проезд в самом Blender, DOF. Субтитры/звук — как в `compose.py` (можно взять оттуда наложение
   субтитров на готовые кадры).

### 9.3 Решения пользователя (не нарушать)
- Субтитры **внизу** (y≈1330), **КАПСОМ**, слова появляются по одному, ключевые слова (`KEY` в render.py) окрашены
  **в акцентный цвет текущего кадра** (третий элемент в `SHOTS`).
- **Никакого огромного текста в начале** (полная первая фраза крупно сверху — отклонено; `BIG_HOOK = False`).
  Одна короткая строчка-заголовок — допустима (тест в 08).
- **Без свечения** (`GLOW = False`). Пробовали ореол вокруг героев (`P.glow`, маска `P.MASK`, `P.LIT`) —
  пользователю не понравились «пятна», решили отключить. Код оставлен, но не включать без просьбы.
- Сердце у героев — **на груди, ниже телефона, крупное** (см. `two_windows` в 07, `her_phone` в 08).
- Новый кадр каждые ~2–4 с, в каждом кадре 2–3 анимации, **у каждой анимации свой звук** (`P.pop/slide/...` сами ставят
  звук через `P.cue`; `sfx.py` синтезирует).
- **Без пауз** между предложениями (`tighten.py`), длина после уплотнения **> 60 с** (180–195 слов ≈ 66–72 с).
- Факты только настоящие, с именем исследователя/годом.
- Связь между героями можно показывать **золотой нитью** (`thread()` в 07/08) — гаснет в тишине, вспыхивает при контакте.

### 9.4 Как сделать новый ролик (конвейер)
1. `mkdir videos/09_<тема>/voice`, написать `script_de.txt` (без кавычек „“ — голос на них спотыкается; 180–195 слов).
2. Озвучка (платно), ключ только из окружения:
   ```
   export LUMEAN_API_KEY=...   # секрет облачного окружения, НИКОГДА не в файл/чат/коммит
   python videos/lumean_client.py order videos/09_x/script_de.txt /tmp/v09    # шаблон Arthur Holm по умолчанию
   cp /tmp/v09/{result.mp3,alignment.csv,subtitles.srt} videos/09_x/voice/
   ```
   Если `alignment.csv` не скачался сразу — сервисные файлы приходят с задержкой, клиент ждёт до минуты.
3. `python videos/tighten.py videos/09_x` → `voice/tight.wav` + `voice/alignment_tight.csv` (печатает длину).
4. `python videos/check_voice.py videos/09_x` — whisper слушает озвучку; сверить с текстом.
5. Скопировать `fonts/` и `render.py` из **`08_entzug`** (последний образец), переписать сцены `sh_*`, список `SHOTS`
   (якорь — начало фразы из текста через `t_of("...")`, функция, акцентный цвет), `KEY`, `TITLE`.
6. Превью кадров: `python render.py /tmp/q --preview 0,1.5,10.2` → png 360×640; смотреть каждый кадр
   (подписи не должны налезать на субтитры у y≈1330).
7. Полный рендер (4 процесса, ~5–8 мин): `python render.py out.mp4` → 1080×1920, 30 fps, голос + музыка + звуки, −14 LUFS.
8. `script_ru.txt`, `beschreibung.txt`, коммит и пуш в ветку `claude/heygen-hyperframes-plugin-etyohh`.

Зависимости (pip): `cairocffi pillow numpy opencv-python-headless faster-whisper`, плюс `ffmpeg` в системе.

### 9.5 Идеи следующих тем (линия kopfgefluester_: боль, расставание, «думает ли он обо мне»)
- «Woran du erkennst, dass er noch an dich denkt» (осторожно с фактами — только то, что подтверждено).
- «Warum er sich zurückzieht, wenn es ernst wird» (избегающая привязанность — исследования есть).
- «Warum Schweigen nach einem Streit mehr weh tut als Worte» (ostracism, Williams — социальная боль).
- Продолжение 07: «Was der denkt, der nicht schreibt».
