## 1. Проект в двух словах

- Один немецкий TikTok-аккаунт, ведут двое (Настя + подруга). Тема: **психология отношений**.
- Аудитория: **женщины 35–55** (в старых правилах канала стояло 40+). Никаких детских, школьных, «девочковых» образов.
- Монетизация Creator Rewards: ролики **дольше 1 минуты** (цель 60–90 с), вертикаль 1080×1920.
- Отвечать пользователю **по-русски**.
- Старый конвейер канала (11 готовых сценариев с озвучкой, рисованные кодом герои, Lumean-озвучка, правила)
  живёт в **другой ветке**: `claude/festive-lovelace-4crmam`, папка `tiktok_de/` (см. её `tiktok_de/CLAUDE.md`).
  Сценарии `tiktok_de/projects/NN_*/script_de.txt`, переводы `script_ru.txt`, озвучка `voice/result.mp3` + `voice/alignment.csv`.

## 2. Где мы сейчас (главное)

**Выбранное направление — мягкие «мармеладные» 3D-фигуры в Blender, как у французского аккаунта `les.zamours2`**
(средне 380 тыс. просмотров, топ 2,1 млн): она — розовая, он — синий, тёмно-синяя спальня/квартира, ночник,
размытый фон, субтитры обычным регистром, текст по формуле «смелое утверждение → «это называют <термин>» → как это
проявляется → тёплый/горький финал».

Пользователю **нравятся фигуры** из `blender_figures/` (лист персонажей `figures_front.jpg`, `figures_back.jpg`).
Утверждено пользователем:
- форма тела как в первой версии листа (`4d46243`), только **равномерно чуть плотнее** (радиусы ×1.16). Не менять плечи/шею/посадку головы без просьбы;
- у неё волосы **распущенные, чуть ниже плеч**, **без чёлки**, лоб и брови открыты, пробор по центру, волосы спереди **не лежат на плечах** — только сзади и по бокам;
- переход волос ко лбу должен быть **плавным, без бортика/ступеньки**;
- всё должно быть **гладенько**, без острых краёв.

**Свисающие волосы — решено (03.11):** одна цельная масса (деформированная сфера), голова и волосы слиты в одну поверхность (voxel remesh + сглаживание), маска «волосы/кожа» переносится с исходной головы, снаружи черепа — всегда волосы. Без швов, прядей и острых краёв; спереди не ложатся на плечи. Крупные планы: `blender_figures/hair_closeup.jpg`. Ниже — история попыток.

**Было (история): свисающие волосы.**
- Тонкая оболочка (shell + solidify) → края «острые/обрывистые» — не понравилось.
- Метаболлы (текущая версия в `blender_figures/figures.py`) → видно отдельные «макаронины» — **не понравилось**.
- Идея, которую не успели проверить: одна **сплошная толстая** оболочка (solidify ~0.06, subsurf 3, сглаженная кромка),
  выходящая из головы по касательной; или sculpt-подобная цельная форма. Без прядей и складок.
- Волосы на самой голове сделаны как часть головы (приподнятая область + плавный переход цвета по маске `hairmask`) —
  это решило «бортик» у лба, оставить.

После волос: поставить фигуры в сцены под конкретный сценарий (кровать — `blender_figures/bed_pair.py`, диван, кухня,
окно), затем ролик.

## 3. Как запускать

### Blender (основной путь)
```bash
mkdir -p /opt/blender && cd /opt/blender && curl -sSL https://download.blender.org/release/Blender4.2/blender-4.2.3-linux-x64.tar.xz | tar -xJ
B=/opt/blender/blender-4.2.3-linux-x64/blender
$B -b -P blender_figures/figures.py -- out/fig 24 0.5     # лист персонажей, превью 540x960 (~20 с на кадр без GPU)
$B -b -P blender_figures/figures.py -- out/fig 32 1.0     # полное качество 1080x1920 (~95 с на кадр без GPU)
$B -b -P blender_figures/bed_pair.py -- out/bed.png 32 1.0  # сцена в кровати (фигуры там старой версии)
```
- Фигуры: Skin modifier + Subdivision (тело), UV-сферы (голова, кисти, стопы), лицо — тонкие торы-дуги и эллипсоиды.
- Рендер Cycles на CPU. В облачной сессии без видеокарты ролик (≈2000 кадров) займёт сутки+; на ПК с GPU — порядка часа.
  Варианты: финальный рендер у пользователя на ПК с GPU, или облегчённый (меньше разрешение/кадров + движение камеры).

### Навыки (уже в репозитории, `.claude/skills/`)
- `blender-film`, `blender-car-film`, `blender-forest` — из https://github.com/mromidev/claude-blender-skills (MIT): мост к открытому Blender, свет, ускорение рендера, очередь рендера. Персонажей не делают.
- `cartoon-3d-short` — из https://github.com/mromidev/claude-animated-shorts (MIT): three.js + Remotion, 2D-«бобы» в 3D-мире. Проект-пример: `animated_shorts/` (рендер без GPU ~1 мин/кадр).
- Плагин HyperFrames (HTML → видео): `claude plugin marketplace add heygen-com/hyperframes && claude plugin install hyperframes@hyperframes`.
  Вход в HeyGen не делали (там генерация картинок nano-banana-2 по $0.067/шт).

### Разбор чужих TikTok-аккаунтов
`tools/tiktok_analyze.sh <account> [N]` — список видео, топ по просмотрам, скачивание (yt-dlp `--impersonate chrome`),
листы кадров, расшифровка голоса (faster-whisper). Скачанные видео в репозиторий не класть.

### Озвучка
Lumean API (см. ветку festive-lovelace: `tiktok_de/lumean/lumean.py`, `tiktok_de/docs/lumean_api.md`).
Ключ — только переменная окружения **`LUMEAN_API_KEY`** в секретах облачного окружения, **никогда** не в файлах/чате.
Пользователь хочет голос **Arthur Holm** (сейчас в шаблоне Ole Carpenter); нужен voice_id и ключ. Озвучка платная.

## 5. Референсы (разобраны)

- **les.zamours2** (FR) — главный референс стиля: мягкие розовая/синий фигуры, тёмно-синяя спальня. 380k средн.
- **psyamour** (FR) — белые манекены, серая квартира, та же формула текста. 188k средн., топ 2,1 млн.
- **noir.mind00** (DE) — hopecore про семью: конкретные воспоминания → «так он говорит „я тебя люблю“» → «напиши ему». Выстрелило после смены темы.
- **ehrenversager** (DE) — чёрные человечки, «Was wäre, wenn du…» + цепочка последствий, 839k на 5-м видео.
- **mindfuel.777** (EN) — неоновый человечек, список 1-2-3, «подтвердите в комментариях»; молодая аудитория.
- **cuentososcuros8** (DE) — красный/белый человечки про нарциссизм, метафора на каждую фразу, 136k.
- Вывод: просмотры делают **тема + формула текста + узнавание**; стиль должен быть взрослым и **с лицами**.
