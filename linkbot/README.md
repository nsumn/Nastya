# Бот-обработчик списков ссылок (linkbot)

Чистит присланный список взаимопиара и готовит его к публикации:

- убирает **смайлики** и всё, что в **скобках** — «(старт)», «(Добавить)»…;
- **сохраняет кликабельность** каждого пункта (исходную ссылку);
- находит ссылку **«Алёна …»** и ставит её на место **«Твоя проверочная ссылка»**,
  переименовывая пункт в **«Те самые новости»**;
- выводит **только список** (без «шапки» и инструкций).

Это **отдельный бот** со своим токеном — он не связан с платёжным ботом.

## Что было / что стало

**Прислали:**
```
🛍️ Вб дарил бесплатно
🫀 Общение (добавь группу)
🔥 Твоя проверочная ссылка
💭 Анонимный чат (старт)
```
**Бот вернул** (каждая строка — кликабельная ссылка):
```
Вб дарил бесплатно
Общение
Те самые новости      ← ссылка «Алёна …»
Анонимный чат
```

## Как запустить

1. Создай **нового** бота у [@BotFather](https://t.me/BotFather) → получи токен.
2. Впиши токен в `.env`:
   ```
   LINK_BOT_TOKEN=сюда_токен_нового_бота
   ```
3. Установи зависимости и запусти:
   ```bash
   pip install -r requirements.txt
   python -m linkbot.bot
   ```
4. Напиши боту **/start** в личку — так он запомнит, кому слать готовый список.

## Полная автоматика (ничего пересылать не надо)

5. Добавь бота **администратором** в свой канал.
6. Когда «Алёна» выложит в канал пост-список — бот сам его почистит, найдёт
   внутри ссылку «Алёна …», подставит её и **пришлёт готовый список тебе в личку**.
   Тебе останется только опубликовать его у себя.

## Ручной режим (запасной)

Просто **перешли** боту список в личку — он почистит и пришлёт ответ.
Если в этом списке нет ссылки «Алёна …», бот возьмёт последнюю, что видел,
а можно дать её вручную — **ответом (reply)** на список отправь нужную ссылку.

## Настройки (`.env`)

| Переменная | Зачем |
|------------|-------|
| `LINK_BOT_TOKEN` | токен нового бота от @BotFather |
| `LINK_BOT_OWNER_ID` | твой chat_id (необязательно — бот запомнит из `/start`) |
| `LINK_BOT_DATA` | файл с состоянием (owner_id и последняя ссылка Алёны) |
| `LINK_BOT_MIN_LINKS` | сколько ссылок в посте, чтобы считать его «списком» |
