# TikTok DE: психология отношений. Правила и пайплайн

Это общий набор для одного немецкого TikTok-аккаунта, который ведут два человека.
Каждое видео должно выглядеть **точно так же**, как `projects/01_wie_mitbewohner`.
Не придумывай новый дизайн. Используй код из `render/` и меняй только сцены и текст.
Отвечай пользователю по-русски.

## Канал
- Немецкий язык, тема: психология отношений и просто психология.
- ЦА: женщины и мужчины 40+, взрослая аудитория. Никаких детских, школьных и «девочковых» образов.
- Монетизация Creator Rewards: видео **дольше 1 минуты** (цель 70–90 с). При публикации ставится AI-метка.
- Не копировать чужие аккаунты (liebe.beziehung и т. п.). Стиль только наш.

## Что отдавать за каждое видео
1. `mp4` 1080×1920, 24 fps.
2. **Перевод сценария на русский**, всегда, без напоминаний (`script_ru.txt`).
3. Описание (`beschreibung.txt`): 2–3 предложения на немецком + ровно 5 хештегов.
   Пример: `projects/01_wie_mitbewohner/beschreibung.txt`.

## Сценарий
- Немецкий, 170–200 слов (≈ 75–85 с). Первая фраза — крючок, конец — призыв (например, «Schick das deinem Partner.»).
- Абзацы разделять `{{pause=0.5}}`.
- **Никаких немецких кавычек „…“ и вообще кавычек:** голос на них мычит. `lumean.py` их не пропускает.
- Факты только настоящие (исследователь, цифры). Не выдумывать.

## Озвучка (Lumean, голос Ole Carpenter)
- Ключ берётся только из переменной окружения `LUMEAN_API_KEY` (секреты облачного окружения).
  **Никогда** не записывать ключ в файлы, в коммиты и в чат.
- `python lumean/lumean.py preview projects/<NN_name>/script_de.txt`: бесплатная проверка нарезки.
- `python lumean/lumean.py order projects/<NN_name>/script_de.txt projects/<NN_name>/voice`: платная озвучка,
  скачивает `result.mp3`, `alignment.csv`, `result.json`, субтитры.
- После озвучки прогнать faster-whisper (`small`, language `de`) и сравнить с текстом.
  Если где-то мычание или пропуск, перегенерировать только этот чанк (docs/lumean_api.md §7.11), а не весь заказ.
- Полная документация API: `docs/lumean_api.md`.

## Визуальный стиль (утверждён, не менять)
- Тёмная ночная комната: графит и navy, лампа, картина, диван или кухня.
- Туман и мягкость **статичные**: никакого мерцания тумана и дрожания линий (`--static --noboil`, уже включено в `video60.py`).
- Персонажи нарисованы кодом (`render/character2.py`), с суставами, двигаются плавно. Пропорции головы: пресет `oval`.
  - **Она:** 30+, волнистые каштановые волосы до плеч, без косичек и прядей спереди, пыльно-розовый оверсайз-свитер,
    круглый вырез (не водолазка), золотые серёжки, подбородок мягкий и не узкий.
  - **Он:** взрослый мужчина 30+ (`MAN = {"adult": True, "beard": "stubble"}`): квадратная челюсть, лёгкая щетина,
    прямые густые брови, тяжёлые веки, пробор набок, шалфейный свитер. Не мультяшный и не «подросток».
  - Когда сидят в телефоне, лица **нейтральные**, взгляд вниз в экран. Улыбка только в тёплых сценах.
  - Телефон держат двумя ладонями по бокам. **Без нарисованных больших пальцев.**
  - Референсы: `characters/*.png`.
- **Монтаж как у liebe.beziehung** (у них по 22–24 смены кадра на 65 с, и почти каждый кадр в новом месте):
  - 22–26 кадров на видео, новый кадр каждые 2–3 с, привязка к словам через `t_of("слово")`;
  - **каждый кадр — новое место или новый ракурс**: одно и то же место не два кадра подряд, за видео минимум 8 разных мест
    (`sets2.py`: спальня, машина, кабинет, прачечная, балкон, парк, прихожая, лестница, ванная, кухня у стойки;
    плюс диван, кухонный стол, телефон крупно, инфографика);
  - эмоции показывать **телом**, а не только лицом: лицо в ладонях, рука на лбу, скрещённые руки, колени у груди,
    голова на плече, жест рукой в споре, отвернулась, лежит без сна; позы задаются через `reach_pose` (IK) и готовые
    `face_in_hands`, `hand_on_forehead`, `arms_crossed`;
  - чередовать общий план, средний и крупный (лицо со слезами), иногда сверху;
  - образец всех мест и поз: `render/demo2.py` → `characters/places_poses.png`.
- Субтитры: Inter Black 70, **белые**, тёмная обводка, **без капса** (обычный регистр), по центру, `SUB_Y = 1330`,
  не больше 3 слов / 16 символов в группе. Розовых акцентов нет.
- Заголовок сверху по центру, белый, первые секунды.
- Безопасные зоны TikTok: сверху ~150 px, справа ~140 px, снизу ~450 px.
- Звук: голос + тихий pad (`assets/pad.flac`, громкость 0.10), около −15 LUFS, пик около −1 dB (это делает `render.sh`).

## Пайплайн
```bash
./setup.sh                                   # один раз в новой сессии
python lumean/lumean.py preview projects/02_x/script_de.txt
python lumean/lumean.py order   projects/02_x/script_de.txt projects/02_x/voice
SHOTS=shots_x .venv/bin/python render/video_v5.py projects/02_x/voice/alignment.csv out --preview 3,12,30,55   # проверить кадры
./render.sh projects/02_x shots_x out/DE_x.mp4      # 20–30 мин, запускать в фоне
```

## Как сделать новое видео
1. Создать `projects/NN_name/` с файлами `script_de.txt`, `script_ru.txt`, `beschreibung.txt`.
2. Озвучить (см. выше).
3. Скопировать `render/shots_tasse.py` (самый новый образец) в `render/shots_NN.py` и переписать `T` (якоря на слова),
   сцены и список `SHOTS` под новый текст: каждый кадр — `(t_of("слово"), функция_сцены, камера)`.
   Готовые элементы (берите их, это наш «фирменный» набор, как в залетевших роликах):
   - плашка-HUD слева сверху (`hud`: день/время, «Studie»), правила с жёлтым ярлыком (`rule_tag`: «Regel 1» + заголовок);
   - кольца-счётчики (`ring`: пульс, «20 Minuten», число мыслей), облако дел (`thoughts`);
   - телефон крупно: экран блокировки с уведомлениями (`lock_phone`), список задач (`tasks_phone`), чат (`video60.sc_phone`);
   - пузыри реплик (`bubble`, можно зачеркнуть), большие цифры/термины (`s_three`, `s_term`), стакан с последней каплей (`s_drop`);
   - 2.5D-дом ночью с отъездом камеры (`building`), кухня (`kitchen_both`), диван (`sofa`), раковина с чашкой (`sink`).
   Позы: `arm_l/arm_r` (жесты), `emo` (явная эмоция), `mug=True` (держит кружку), `phone=0..1`.
4. Рендерить через `SHOTS=shots_NN` (см. пайплайн). Персонажей, руки, телефон и субтитры не трогать.
5. Сначала превью кадров (`--preview`), показать пользователю, потом полный рендер.
6. Готовое видео + русский перевод + описание отдать пользователю.

## Модули `render/`
- `character2.py`: риг персонажей (позы, эмоции `neutral|calm|smile|happy|sad|worried|angry|cry|closed`, моргание, рот).
- `video_v5.py`: рендерер. Модуль кадров выбирается переменной `SHOTS` (по умолчанию `video_shots`).
  Подставляет риг в сцены, сидячие позы, телефон/кружку в руках, белые субтитры, эмоции.
- `video_shots.py`: кадры Mitbewohner (образец 1) и общие блоки (диван, кухня, большой телефон).
- `shots_tasse.py`: кадры «Warum sie wegen einer Tasse explodiert» (образец 2, с HUD, правилами, счётчиками).
- `video60.py`: тайминг по alignment, группы субтитров, комнаты, крупный план телефона, статистика.
- `sofa_fog.py`: финальный «look» (туман, блюр, bloom, зерно, виньетка).
- `adult.py`, `storybook.py`, `sofa_anim.py`: базовые наборы и фон.
- `man_test.py`, `hands_test.py`: быстрые листы для проверки лиц и рук.
