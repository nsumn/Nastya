# 09 «Je liebevoller sie war…» (Beziehungs-Burnout) — раскадровка

Сделано по навыку vizavi_motion (`.claude/skills/vizavi-motion`): одна нить, по 3 варианта на сцену, выбранный вариант, камера/слои/переход/звук.

**Нить:** её тепло — это свеча, которая горит для двоих. В начале она горит ярко (воспоминания: бежит к двери, сердечки),
дальше её «расходуют» по мелочам (пакеты, календарь, вся семья на ней), свеча догорает, и в конце становится понятно: её тепло не
пропало, оно устало ждать. Финал рифмуется с началом: она у окна под дождём.

**Бриф:** 1080×1920, 30 fps, H.264 + AAC, ~64 с, голос Lumean (Ole Carpenter) + музыка (синтез-фортепиано, ноты на ключевых
склейках) + SFX (дождь, шаги, ключи, дверь, телефон, пакеты). Субтитры — утверждённый стиль (белые, внизу, без капса).
Камера в каждом плане едет по плавной траектории (не линейный зум), передний план размыт и смещается сильнее (параллакс, DOF),
на 5 переходах — быстрый проезд со смазом (whip).
