# 🐾 Котохозяйство: Кики, Лаки и Пуся

Telegram-мини-приложение с ачивками, чтобы не забывать ухаживать за котиками.

**Каждый день:**

| Дело | Сколько раз |
|------|-------------|
| 🧻 Поменять лоток | 2 раза |
| 💧 Водичка: кухня, коридор, комната | по 1 разу |
| 🍗 Подсыпать корм | 1 раз |

## Что умеет

- Каждое дело — пузырь как у **поп-ита**. Нажимаешь, слышишь «поп»,
  телефон вибрирует, во все стороны разлетаются **кошачьи лапки**.
- Котики в шапке меняют настроение: грустные глазки, пока ничего
  не сделано, и счастливые с сердечками после идеального дня.
  Если нажать на котика, он мурчит и говорит, чего ему не хватает.
- **Несколько человек, всё синхронизируется.** Дела общие: если кто-то
  поменял лоток, у всех он отмечен (видно кто и во сколько). Приложение
  подтягивает изменения каждые 15 секунд. Если двое нажмут одновременно,
  засчитается одно нажатие.
- **Статистика и ачивки у каждого свои**: личная серия дней заботы,
  рекорд, сколько лотков, водичек и кормёжек сделал(а) именно ты,
  свои последние 14 дней.
- **Отмена случайного нажатия**: под каждой своей отметкой есть кнопка
  «↩ отменить» (работает весь день), а сразу после нажатия ещё и во
  всплывашке. Отменить можно только свою отметку.
- **19 личных ачивок**: «Неделя заботы», «Супергерой дня» (все 6 дел
  в одиночку), «Команда мечты» (идеальный день вместе с кем-то),
  «Кики довольна», «Повелитель лотков», «Ранняя пташка» и другие.
- **Раздел «Семья»**: сколько идеальных дней подряд у всей семьи
  и кто больше заботился за неделю.
- **Вечерние напоминания** (по умолчанию в 20:00 и 22:30): бот присылает,
  что сегодня ещё не сделано. Если сделано всё, он хвалит.

Демо без сервера: открой `/?demo=1`.

## Команды бота

- `/start` — открыть приложение
- `/today` — что осталось сегодня
- `/reminders` — включить или выключить напоминания

## Запуск

Пошагово для сервера: [deploy/DEPLOY.md](deploy/DEPLOY.md).

Локально (без Telegram, для проверки):

```bash
python3 -m venv .venv && .venv/bin/pip install -r requirements.txt
DEV_MODE=1 .venv/bin/python -m catbot.main   # http://127.0.0.1:8090
```

## Настроить под себя

- Цвета котиков: массив `CATS` в начале `webapp/app.js`.
- Дела и ачивки: `catbot/tasks.py` (и `webapp/demo.js` для демо).
- Время напоминаний: `REMINDER_TIMES` в `.env`.

## Структура

```
catbot/
  main.py       — точка входа: бот + веб-сервер + напоминания
  bot.py        — команды /start, /today, /reminders
  web.py        — API для мини-приложения
  auth.py       — проверка подписи Telegram
  service.py    — отметка дел, сборка состояния
  tasks.py      — дела, статистика, ачивки
  reminders.py  — вечерние напоминания
  db.py         — SQLite
webapp/
  index.html, style.css, app.js — само приложение
  demo.js       — демо-режим без сервера
deploy/         — systemd, Caddy, инструкция
```
