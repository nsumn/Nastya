# Сценарий 10 (erlernte Hilflosigkeit) — взрослые человечки на тёмной сцене

- Герои из правил канала: она — пыльно-розовый свитер, каштановое каре, золотая серёжка; он — шалфейный свитер, щетина.
- Лица без эмодзи: точки-глаза, брови (нейтральные/грустные), рот (линия/открыт/грусть), моргание.
- Риг с суставами (бёдра, колени, плечи, локти, наклон корпуса, кивок головы) — анимация через GSAP.
- 25 планов по словам озвучки, субтитры сверху, ключевые слова розовым.
- `python3 hilflos.py <scratch>` собирает `index.html` (нужны `v10/words.json`, `assets/voice.mp3`, `assets/bed.wav`).
