# Пробные кадры: человечки-метафоры (тема Love Bombing)

Стиль по разбору ролика про нарциссизм (белый фон, линия земли, человечки, одна метафора на фразу),
но со своими героями канала: она — белая с каштановыми волосами и золотой серёжкой, он — красный.
Текст на немецком, в третьем лице (правила `tiktok_de/CLAUDE.md`).

1. Am Anfang ist er perfekt. — встал на колено с букетом, сердца.
2. In der Psychologie: Love Bombing. — на неё падают сердца-бомбы с фитилями.
3. 50 Nachrichten am Tag. — телефон с сердечками и счётчиком 50.
4. Dann wird er kälter. — он отвернулся, нить провисла, снежинки.
5. Mal warm, mal kalt: intermittierende Verstärkung. — игровой автомат: сердце / снежинка / сердце.
6. Sie wartet auf den Mann vom Anfang. Den gab es nie. — она с фото «того» его, на земле улыбающаяся маска.

`python3 stick.py index.html` пересобирает композицию HyperFrames (6 сцен по 2 с, пока без анимации).

## Тёмная версия (`frames_dark/`, `stick_dark.py`)
Графитово-синий фон (палитра канала), конус света-прожектора и тёплое пятно на земле под героями,
светлая линия земли, белый заголовок с красным акцентом. Пересборка: `python3 stick_dark.py index_dark.html`.
