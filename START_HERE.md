# С чего начать (для работы с Claude над видео «What if…»)

Здесь лежит всё, что нужно, чтобы делать 3D-ролики «What if…» для TikTok в том же стиле: движок, все прошлые видео, правила канала и навыки для Claude.

## Американский канал «What if…» — что сейчас (3 ноября 2026)
- Последнее готовое видео в старом стиле: «What if you could fly for one day?» (`earthstop/parts_fly/`).
- Видео в старом low-poly стиле перестали набирать просмотры. Решили переходить на реалистичные короткие ролики в Блендере в стиле Zack D. Films (20–40 с, голос за кадром, тело/опасность/странные случаи). Блендер на облачном сервере работает: `BLENDER=1 bash earthstop/setup.sh`. Замеры скорости и открытые вопросы — в начале `earthstop/HANDOFF.md`.
- На этой же ветке работают двое (два разных Claude Code): американские «What if» и корейские шортсы. Перед push всегда `git fetch` + `git rebase`, никогда не делать force-push.

## Корейский канал 뚝딱 (@ttukttak3d)
Для корейских роликов главный файл — `earthstop/KOREA.md`: канал, правила и замечания, герой-кореец, движок, текущий ролик в работе и следующие идеи. Перед работой и перед каждым пушем: `git pull --rebase origin claude/what-if-video-ideas-nmv78w` (в эту же ветку пишет сессия американского канала).

## Где что лежит
- **Ветка:** `claude/what-if-video-ideas-nmv78w`. Вся работа там, а не в `main`.
- `earthstop/`: движок (three.js + Python для звука), сцены всех видео, инструменты расчётов.
  - `earthstop/HANDOFF.md`: текущее состояние и все замечания по прошлым видео. Это главный файл.
  - `earthstop/CLAUDE.md`: как Claude должен работать: процесс, безопасные зоны TikTok, рендер, кодирование, ошибки.
  - `earthstop/README.md`: список всех сцен и переиспользуемых частей (город, люди, карта США, глобус, герой и друг).
- `.claude/skills/`: навыки Claude, подхватываются автоматически:
  - `whatif-tiktok-video`: как делать ролик в этом движке;
  - `vizavi-motion`: качество моушена: камера, motion blur, глубина резкости, кинетический текст, звук, проверка.
- `bot/`, `deploy/`: отдельный Telegram-бот, к видео не относится.

## Как начать в Claude Code (в браузере, claude.ai/code)
1. Подключить GitHub-аккаунт, на котором лежит репозиторий `nsumn/Nastya`.
2. Создать сессию с этим репозиторием и выбрать ветку `claude/what-if-video-ideas-nmv78w`. Либо написать Claude: «работаем в ветке claude/what-if-video-ideas-nmv78w».
3. Первым сообщением написать, например: «Прочитай earthstop/HANDOFF.md и earthstop/CLAUDE.md, запусти bash earthstop/setup.sh и предложи 5 идей What if». Дальше Claude ведёт сам: идеи → сценарий с фактами → согласование → рендер → видео и описание для TikTok.

Локально тоже можно: `git clone`, `git checkout claude/what-if-video-ideas-nmv78w`, `bash earthstop/setup.sh`. Нужны Node 18+, Python 3, ffmpeg, Chromium через Playwright.

## Что НЕ лежит в репозитории (и почему)
- **Готовые mp4, кадры, wav** (`earthstop/out/`): они тяжёлые. Их можно перерендерить из исходников командами из `earthstop/CLAUDE.md`.
- **Чужая музыка** (например, трек из TikTok-челленджа): её нельзя выкладывать. Видео рендерится без неё, а звук добавляется в самом TikTok.
- **Ключ озвучки Lumean.** Ключ личный, в репозиторий его класть нельзя. Чтобы делать видео с голосом, нужен свой ключ с lumean.app. Его передают Claude в сессии или задают как `LUMEAN_API_KEY`. Инструмент для озвучки: `earthstop/tools/lumean.py`. Голос «Andrew» (американский) там уже указан.

## Важно
- Общение на русском, текст на экране на английском, единицы американские (мили, футы, °F).
- Каждый факт проверяется поиском и даётся с источником. Расчёты лежат в `earthstop/tools/*.py`.
- После каждого шага Claude коммитит и пушит изменения в эту ветку, чтобы следующая сессия начиналась с актуального движка.
