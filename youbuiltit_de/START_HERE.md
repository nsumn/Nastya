# С чего начать: немецкий TikTok «Wie es gebaut wird»

Совместный проект. Мы делаем 3D-ролики в стиле американского аккаунта @youbuiltit, но на немецком: «Wenn du ein Loch gräbst… Aber… Also… Glückwunsch! Du hast einen Keller gebaut.».

## Где что лежит
- **Репозиторий:** `nsumn/Nastya`, **ветка `claude/youbuiltit-frames`**. Вся работа идёт там, не в `main`.
- `youbuiltit_de/CLAUDE.md`: главный файл для Claude. В нём формат, конвейер по шагам, команды, грабли и ключи.
- `youbuiltit_de/01_keller/`: готовый ролик про подвал (`DE_01_keller.mp4`).
- `youbuiltit_de/02_burg/`: готовый ролик про рыцарский замок (`DE_02_burg.mp4`).
- `youbuiltit_de/engine/`: 3D-движок (three.js + Playwright + ffmpeg) и сцены обоих роликов.
- `youbuiltit_frames/`: разбор оригинального аккаунта (кадры).
- `bot/`, `deploy/`: отдельный Telegram-бот, к видео не относится.

## Как начать в Claude Code (claude.ai/code)
1. Подключить GitHub-аккаунт с доступом к `nsumn/Nastya`.
2. Создать сессию с этим репозиторием и веткой `claude/youbuiltit-frames`.
3. В настройках окружения добавить переменную `LUMEAN_API_KEY` с ключом от lumean.app. Он нужен для озвучки, без него можно делать только картинку.
4. Вставить первым сообщением текст из `youbuiltit_de/PROMPT_FOR_FRIEND.md`.

Локально всё работает так же: `git clone`, `git checkout claude/youbuiltit-frames`, `bash youbuiltit_de/setup.sh`. Нужны Node 18+, Python 3 и ffmpeg.

## Чего нет в репозитории
- **Ключа Lumean.** Он личный, передаётся только через переменную окружения.
  Если ключ свой (другой аккаунт Lumean), Claude один раз создаст шаблон голоса Lennard командой `python3 lumean.py template`.
- `node_modules`, кадры и промежуточные куски рендера. Они ставятся и пересобираются командами из CLAUDE.md.

## Как устроена работа
1. Тема.
2. Немецкий текст на 60–65 с (плюс русский перевод).
3. Озвучка голосом Lennard, затем паузы ужимаются.
4. 3D-сцена, где каждое действие привязано к слову.
5. Проверка стоп-кадрами.
6. Полный рендер (30–60 мин).
7. Готовый mp4 + описание + 5 хештегов.

После каждого шага Claude коммитит и пушит изменения в ветку, чтобы у второй из нас было актуальное состояние.
