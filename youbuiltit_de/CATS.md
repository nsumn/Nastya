# Кошачьи аккаунты: Mimi, Flocke, Momo

Этот файл для Claude. Прочитай его целиком перед любой работой с кошачьими роликами.

Общий конвейер описан в `CLAUDE.md`: озвучка, рендер, субтитры, ключи. Здесь только то, что относится к котам.

Правила:
- Общение с заказчицей (Настя) на русском.
- Текст на экране и озвучка на немецком, обращение к зрителю на «du» и «ihr».

## 3. Где что лежит

### Движок
- Папка: `engine/`.
- 2D-сцена — файл `engine/<name>_2d.js`. `render_video.sh` сам копирует его в `<name>.js`.
- Страница: `engine/index_<name>.html`. Это копия `index_flocke2.html` с другим `.js`.
- Рендер:
  ```bash
  cd youbuiltit_de/engine && ./render_video.sh <name> <NN_папка>
  ```
  2D идёт быстро: 45 с видео рендерятся примерно за 5–8 минут.

| Flocke | `flocke_2d.js`, `flocke2_2d.js` (Tag 2), `flocke3_2d.js`, **`flocke4_2d.js` (Tag 3, лучший образец нового формата)** | `flocke4_2d.js` |
| Momo | `insel_main.js`, `kurz_main.js`, `momo2_main.js`, `momo3_main.js` (3D: `cat lib.js NN_main.js`) | `momo3_main.js` |

### Как устроена 2D-сцена (`flocke4_2d.js`)
- Наверху стоят `WORDS`, `T('Wort', n)` и объект `tw` с временами слов, а также `SFX`: звуки по словам, их микширует `sfx.py`.
- Ниже идут хелперы, их копируй как есть. Про `CROWD` ниже отдельно.

| Хелпер | Что делает |
|---|---|
| `cat(x, y, s, o, t)` | котёнок с обводкой |
| `LOOKS` | окрасы: tabby, ginger, tuxedo, calico, siamese, pink, transflag, sphynx… |
| `o.acc` | аксессуары: bee, glasses, crown, wings, antenna, hat, bow |
| `o.mood` | настроение: happy, sad, wow, neutral, tired |
| `garden()` | сад Флоки |
| `room()` | комната Мими |
| `card`, `counter`, `button`, `chip`, `bubble` | интерфейс |
| `polaroid`, `nameWall` | фото и стена ников |

- `CROWD` — толпа котят. Если данных комментаторов нет, она рисуется обычными окрасами (подробнее в «Данных комментаторов» ниже).
- Новые хелперы в `flocke4_2d.js`: `tape` (лента-заголовок сцены), `sticker` (красная плашка), `profileCard` (карточка профиля TikTok со счётчиком), `townSign`, `stamp`, `goalCard`, `ladder`, `ausweis`, `commentBox`, `kater`, `grey()`, постройки `well`, `fishStand`, `fireStation`.
- `frame(t)` — таймлайн. Сцены меняются по словам, каждая привязана к `tw.*`.

### Субтитры
- Всегда отдельным слоем: `NN_папка/captions.json`, подробности в `CLAUDE.md`, п. 5a.
- Поменял субтитры → снова запусти `render_video.sh`: пересчитается только слой.
- В Tag 3 Флоки субтитры: `phrase`, y 1120, розовое выделение; `moves` переносит их вниз на сцене с пропуском, `hide` убирает их на финальной карточке.

### Голос
- Lennard через Lumean, как в строительном канале: `lumean.py order` → `tighten.py <dir>/voice 0.2` → `make_words.py <dir>`.
- Если соединение рвётся: `lumean.py resume <dir>/voice`. Повторять, пока не появится `voice/alignment.csv`.
- **Ключ** берётся только из окружения, см. `CLAUDE.md`, раздел 6. В файлы и коммиты его не класть.

### Грабли окружения (2026-11-09)
- `setup.sh` ставит в `engine/node_modules` свой playwright, а он не находит встроенный в контейнер браузер. Удали `engine/node_modules/playwright*` и не коммить изменённый `package-lock.json`.
- `sfx.py` нужен `scipy` (`pip install scipy`). Без него ролик собирается без звуков и музыки, а ошибку видно только в логе.
- Большие холсты (карта 3000×3000) в SwiftShader иногда теряют содержимое посреди кадра: чёрные полосы сверху и снизу. Лечится `getContext('2d', { willReadFrequently: true })` у всех холстов сцены и `g.reset()` в начале кадра. После рендера проверяй все кадры mp4, а не только контактный лист.
- Перед новым эпизодом перечитай тексты прошлых роликов аккаунта: незакрытые вопросы, обещания и обрывы надо продолжать.
- Ники комментаторов в сцене не прописываем: в 21 они лежат в локальном `21_mimi_tag3/roles.json` (gitignored), без него сцена рисуется без ников.

## 4. Формат, который сейчас работает (разбор @vyral696, 2026-11-09)

Аккаунт [@vyral696](https://www.tiktok.com/@vyral696): бундесвер, «я новобранец, каждый подписчик — мой товарищ». За два дня у него 4 ролика: 75K, 17K, 46K и 48K просмотров.

Тему не копируем, переносим приёмы:

1. **Сериал с обрывом.** Каждый ролик кончается обрывом («…und dann ging die Sirene los») и обещанием «Teil 2 heute Abend». Подписываются, чтобы узнать продолжение. Голое «Folg mir» не работает.
2. **Живой счётчик.** «Gestern 2.000 → heute 2.554» на карточке профиля, цифра обведена, рядом стикер «+554 NEUE». Зритель видит, что подписки работают.
3. **Лестница целей с прогресс-баром.** Garten → Dorf → Stadt (ab 5.000) и «NOCH 2.446». У каждой ступени видна награда.
4. **Комментарий за награду с дефицитом.** «Schreib „Pfote", dann bekommst du deinen Dorfausweis. Nur die ersten 5.000!»
5. **Решает топ-комментарий.** «Lassen wir ihn rein? Euer Top-Kommentar entscheidet.»
6. **Комментаторы получают роли в сюжете.** Например, Feuerwehrchef Niklas (@fortnitykidyy), Köchin Cookie (@lilli6506), Königskatze с дёнером (@tilda_matildaa01).
7. **Темп.** Кадр меняется на каждое слово, примерно раз в секунду. Сверху лента с названием сцены, яркие стикеры с цифрами.
8. **Длина 40–45 с,** около 120 слов.
9. **Выкладывать 2 раза в день.** В названии «Tag N», в описании вопрос и «Teil 2 heute Abend».

Шаблон текста:
> Tag N in Flockes Garten. Gestern waren wir X. Heute sind wir schon über Y! → Награда/новый уровень → 2–3 комментатора получают роли → Nächstes Ziel → Schreib „…" → Doch dann… (обрыв) → Frage + Top-Kommentar entscheidet → Teil 2 kommt heute Abend.

Числа показываем **только на экране** (константы `FOLLOWERS`, `YESTERDAY`, `GOAL` в начале сцены). В голосе округляем («über zweitausendfünfhundert»), тогда при новой цифре озвучку не надо переделывать.

Описание к посту строится так: 2–3 строки, вопрос, призыв к комментарию, «Teil 2 heute Abend». Хештеги: `#tagN #katze #kätzchen #<тема> #fyp`.

## 5. Чего заказчица не любит
- Медленные ролики, а также бессмысленные цифры («37 дней» её раздражали).
- Мало котят на экране: если подписчиков 300+, котят на экране должно быть сотни.
- «Список домиков» вместо настоящего города: нужны улицы, река, мосты, парки, площадь.
- Злые брови у грустной героини.
- Субтитры поверх морды героини.
- Хук не должен быть вялым: первая секунда сразу цепляет (грусть, цифра, конфликт).

## 6. Сбор комментариев TikTok
Полная пошаговая инструкция — в `COMMENTS_HOWTO.md`.
Собирать только публичные комментарии и только для того, чтобы показать ник и желание в ролике.

```bash
cd youbuiltit_de
mkdir -p /tmp/tt && cd /tmp/tt
python3 /home/user/Nastya/youbuiltit_de/tools/fetch_comments.py <video_id> comments.json   # все комментарии (count=50, листает cursor)
python3 /home/user/Nastya/youbuiltit_de/tools/fetch_replies.py <video_id>                  # ответы на комментарии -> replies.json
```

Пояснения к скриптам:
- `has_more` иногда кончается раньше времени. Если комментариев заметно меньше, чем показывает TikTok, запусти ещё раз и объедини результаты по `cid`.
- Фото комментариев лежат в поле `images`. Скачивай их по URL. HEIC переводи в JPG через `pillow_heif`.
- Список роликов и id:
  ```bash
  .venv/bin/yt-dlp --impersonate chrome --flat-playlist -J https://www.tiktok.com/@<handle> > list.json
  ```
  Подробнее в `CLAUDE.md`, раздел 7.

Окрас и аксессуар (`look`, `acc`) для `cats.json` расставляй сам:
- по тексту желания («rosa Kätzchen, das Pommes heißt» → `pink`, name Pommes);
- по фото: смотри контактный лист фото и выбирай ближайший `LOOKS`.

## 7. Правила работы
- **Ветка для кошачьих роликов: `claude/cats`** (создана от `claude/youbuiltit-frames`). После каждого шага коммить и пушь туда.
- Перед полным рендером всегда проверяй стоп-кадры (контактный лист). Перед сдачей проверь кадры из готового mp4.

- В коммиты не кладём ключи, данные комментаторов и идентификатор модели.
