# 01 — Wie ein Loch im Garten zum Keller wird

Формат @youbuiltit (разрез земли, газон, дом, субтитры по одному слову), но немецкий:
дом с черепичной крышей и рольставнями, немецкие темы (Keller, weiße Wanne, Lichtschacht).
Голос: Lumean, шаблон «DE Wie es gebaut wird – Victor Voss» (`01a19cc2-21f4-71d2-8350-d972ccc61e0f`).
Озвучка: `voice/result.mp3` (92 с) + `alignment.csv` для субтитров по словам.
Для сравнения: `voice_ole/result_ole.mp3` (тот же текст, Ole Carpenter, 71 с).

| # | Фраза | Кадр (разрез) |
|---|---|---|
| 1 | Ein Loch im Garten… | газон перед домом, разрез земли; яма раскрывается |
| 2 | Zuerst kommt der Bagger… | экскаватор копает, котлован шире контура дома (пунктир) |
| 3 | Sauberkeitsschicht | на дно ложится тонкий серый слой |
| 4 | Bewehrungsstahl / Bodenplatte | сетка арматуры, заливка плиты ~25 см |
| 5 | Wasser drückt | синий грунт снизу, белые стрелки давят на стены и плиту |
| 6 | weiße Wanne | стены растут из плиты, бетон белеет; капли отскакивают |
| 7 | Fugenblech | крупный план шва, стальная полоса встаёт в шов |
| 8 | Dämmplatten | снаружи на стены приклеиваются розовые/зелёные XPS-плиты |
| 9 | Lichtschacht | у окна подвала ставится приямок с решёткой, свет падает внутрь |
| 10 | zugeschüttet | земля засыпает котлован, сверху газон |
| 11 | Waschmaschine, Vorräte, Fahrrad | разрез готового подвала: стиралка, полки с банками, велосипед |
