# Темы для ролика 03 (на выбор)

Проверка движка 2026-11-03: `setup.sh` прошёл, стоп-кадры 02_burg (5, 30, 55 с) рендерятся, ~3 с на кадр.
Озвучка пока недоступна: в окружении нет `LUMEAN_API_KEY`.

Каждая тема держит 5–6 пар «Aber → Also», все решения реальные.

## 1. Autobahn: Wie ein Feldweg zur Autobahn wird
Feldweg → **Aber** Frost hebt die Straße → **Also** Frostschutzschicht aus Kies →
**Aber** Lkw drücken Spurrinnen → **Also** Tragschicht + Asphalt in Lagen →
**Aber** Frontalunfälle → **Also** Mittelstreifen + Leitplanke →
**Aber** Kreuzungen → **Also** Auffahrten und Autobahnkreuz (Kleeblatt) →
**Aber** Lärm im Dorf → **Also** Lärmschutzwand →
**Aber** Panne → **Also** Standstreifen + orange Notrufsäule etwa alle 2 km.
Плашки: «2 km», «3 Spuren». Самая узнаваемая немецкая тема.

## 2. Fachwerkhaus: Wie ein Holzgerüst zum Fachwerkhaus wird
Pfosten in der Erde → **Aber** Holz fault im Boden → **Also** Steinsockel + Schwelle →
**Aber** das Gerüst kippt → **Also** Streben und Andreaskreuze →
**Aber** Löcher in der Wand → **Also** Gefache: Staken, Flechtwerk, Strohlehm →
**Aber** Regen wäscht den Lehm aus → **Also** Kalkputz + Dachüberstand →
**Aber** die Gasse ist eng → **Also** jedes Stockwerk kragt vor →
**Aber** Stadtbrand → **Also** Brandmauer aus Stein.
Очень «немецкая» картинка, уютный мультяшный стиль.

## 3. Römische Wasserleitung nach Köln (Eifelwasserleitung)
Quelle in der Eifel → **Aber** Köln ist 95 km weit weg → **Also** Rinne mit gleichmäßigem Gefälle →
**Aber** Frost → **Also** etwa 1 m tief unter der Erde →
**Aber** ein Tal → **Also** Aquäduktbrücke mit Bögen →
**Aber** Schmutz → **Also** Absetzbecken →
**Aber** Kalk setzt sich ab → **Also** Revisionsschächte zum Reinigen.
Финальный факт: Kalksinter später als «Aquäduktmarmor» in Kirchen verbaut. Немецкая и историческая сразу.

## 4. Schleuse und Schiffshebewerk
Kanal zwischen zwei Flüssen → **Aber** Höhenunterschied, das Wasser läuft weg → **Also** zwei Tore = Schleusenkammer →
**Aber** Wasserdruck drückt die Tore auf → **Also** Stemmtore, die gegen den Strom zeigen →
**Aber** jede Schleusung kostet Wasser → **Also** Sparbecken →
**Aber** 36 m Höhe → **Also** Schiffshebewerk Niederfinow (1934): das Schiff fährt im Wassertrog Aufzug.
Очень наглядно: вода поднимается, корабль едет вверх.

## 5. U-Bahn: Wie ein Loch in Berlin zur U-Bahn wird
Graben unter der Straße → **Aber** die Straße ist weg → **Also** Tunnel mit Deckel (offene Bauweise), später Tunnelbohrmaschine →
**Aber** Grundwasser → **Also** dichte Tübbinge →
**Aber** Dampfloks unter der Erde → **Also** elektrisch, Stromschiene 750 V →
**Aber** stickige Luft → **Also** Lüftungsschächte →
**Aber** Gedränge → **Also** Bahnsteig auf Wagenhöhe.
Финал: Berlins erste U-Bahn fuhr 1902.
