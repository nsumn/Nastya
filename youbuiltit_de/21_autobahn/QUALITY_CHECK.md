# 21 Autobahn: проверка по критериям TikTok (2026-11-11)

| Критерий | Ролик | Итог |
|---|---|---|
| Оригинальность (свой контент, без чужих водяных знаков, не нарезка) | своя 3D-сцена, свой текст | ✅ |
| Длина больше 1 мин (условие Creator Rewards) | 69.4 с | ✅ |
| Техника: 1080×1920, 9:16, 30 fps | да, H.264 High, ~9.3 Мбит/с | ✅ |
| Звук: громкость | −20.1 LUFS, моно 44.1 кГц | ⚠️ тише обычного для соцсетей (~−14 LUFS), стоит поднять |
| Удержание: хук в первые 1–2 с | голос сразу, но картинка статичная: машинка на тропинке, туман | ⚠️ слабый визуальный хук |
| Удержание: темп | ~3.5–4 слова/с, событие на каждом «Aber/Also» | ✅ |
| Читаемость: подписи в безопасной зоне | «Fr…» (Frostschutz), «3 Spuren», «alle 2 km» обрезаны краем кадра | ❌ исправить |
| Безопасная зона интерфейса TikTok | субтитры по центру (y=990) ок; плашки у правого края попадают под кнопки | ⚠️ |
| Ценность для поиска | слово «Autobahn» есть в описании и хештегах | ⚠️ добавить фразу-запрос и заголовок на первом кадре |
| Метка ИИ | реалистичный синтетический голос (ElevenLabs) | ⚠️ включить «AI-generated content» при публикации |

Исправления (по порядку пользы):
1. Сдвинуть плашки «Frostschutzschicht», «3 Spuren», «alle 2 km» к центру (x 150–900 px) и перерендерить только эти куски.
2. Поднять громкость: `ffmpeg -i DE_21_autobahn.mp4 -c:v copy -af loudnorm=I=-14:TP=-1.5:LRA=11 -c:a aac -b:a 192k -ac 2 out.mp4`.
3. Хук: первые 1.5 с — пробка или авария на тропинке в грязи, или заголовок «Warum Autobahnen so gebaut werden» поверх кадра.
4. В описание добавить поисковую фразу: «Wie wird eine Autobahn gebaut?».
5. При публикации включить метку AI-generated content (голос синтетический).
