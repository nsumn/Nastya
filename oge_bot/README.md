# Telegram-бот для подготовки к ОГЭ 📚

Бот присылает материалы для подготовки к ОГЭ: конспекты, формулы и подсказки по
предметам. Работает в двух режимах:

- **Меню по темам** — пользователь выбирает предмет → тему → материал, и бот
  присылает конспект (с текстом, при необходимости файлом и ссылкой).
- **Ежедневная рассылка «материал дня»** — подписчики каждый день получают по
  одному материалу, чтобы готовиться понемногу, но регулярно. У каждого своя
  позиция в ленте, поэтому материалы не повторяются, пока не закончатся.
- **Магазин сборников** — кнопка «🛒 Купить сборник»: покупатель выбирает
  предмет ОГЭ, видит цену и реквизиты карты, оплачивает и присылает чек. Чек
  уходит админу магазина, тот вручную проверяет оплату и присылает файл,
  переписываясь с покупателем прямо в боте. Каждый сборник — «два в одном»:
  прорешённые задания открытого банка ФИПИ + справочные материалы (формулы и
  понятия) одним пакетом.

## Сценарий

1. `/start` → приветствие и главное меню.
2. **📚 Материалы** → выбор предмета → темы → материала.
3. **🎲 Материал дня** → бот сразу присылает следующий материал.
4. **🔔 Подписаться на рассылку** → каждый день в заданное время приходит
   новый материал. Отключить — кнопкой или `/unsubscribe`.

## Команды

| Команда | Действие |
|---------|----------|
| `/start` | Главное меню |
| `/materials` | Список предметов |
| `/shop` | Купить сборник |
| `/today` | Получить материал прямо сейчас |
| `/subscribe` | Включить ежедневную рассылку |
| `/unsubscribe` | Выключить рассылку |
| `/help` | Справка |

## Установка

```bash
python3 -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt

cp oge_bot/.env.example .env   # заполни BOT_TOKEN
python -m oge_bot.main
```

## Настройка (`.env`)

- `BOT_TOKEN` — токен от [@BotFather](https://t.me/BotFather) (обязательно).
- `ADMIN_CHAT_ID` — твой `chat_id` (необязательно).
- `DB_PATH` — путь к файлу SQLite с подписчиками (по умолчанию `oge_bot.db`).
- `DAILY_ENABLED` — включить ежедневную рассылку (`1`/`0`).
- `DAILY_SEND_TIME` — время рассылки по локальному времени сервера, формат `ЧЧ:ММ`.
- `SHOP_ADMIN_CHAT_ID` — чат админа, обрабатывающего покупки сборников (если
  пусто — используется `ADMIN_CHAT_ID`).
- `CARD_DETAILS` — реквизиты для оплаты картой РФ, показываются покупателю.

## Как покупатель оплачивает сборник

1. **🛒 Купить сборник** → выбор предмета → цена + реквизиты карты.
2. **✅ Оплатил — отправить чек** → покупатель присылает чек/скриншот.
3. Чек приходит **админу магазина** (`SHOP_ADMIN_CHAT_ID`) в личку.
4. Админ отвечает **reply** на сообщение покупателя — ответ (текст или файл со
   сборником) приходит покупателю прямо в чат бота.

Цены и список предметов настраиваются в `oge_bot/shop.py`.

## Документы (FAQ, оферта, политика)

Под полем ввода — постоянная нижняя клавиатура: **Помощь**, **Контакты**,
**Политика конфиденциальности**. В самом меню (инлайн-кнопками) — **FAQ** и
**Пользовательское соглашение**.

Документы (оферта, политика, FAQ) показываются **текстом прямо в боте** —
тексты лежат в `oge_bot/legal.py`. Документы обезличены (от лица «Администрации»),
без персональных данных и без даты публикации. Длинные тексты бот автоматически
отправляет частями (лимит Telegram — 4096 символов на сообщение).

При желании документ можно вынести на внешнюю страницу: впиши ссылку в
`TERMS_URL` / `PRIVACY_URL` / `FAQ_URL` (по умолчанию `None`), и кнопка станет
вести на неё вместо текста в чате.

`CONTACT_USERNAME` — Telegram-юзернейм для связи (кнопка «Контакты» и упоминания
в документах), сейчас `anastasiiabuyer`.

На экране оплаты есть строка «Оплачивая, вы соглашаетесь с пользовательским
соглашением и политикой конфиденциальности».

## Как добавить материалы

Весь учебный контент лежит в `oge_bot/content.py` в виде обычной структуры
данных. Чтобы добавить материал, тему или целый предмет — просто допиши туда:

```python
Material(
    id="math_numbers_3",            # уникальный id
    title="Проценты",               # заголовок (кнопка и шапка)
    text="<b>Проценты</b>\n...",    # текст урока (поддерживается HTML)
    file="files/percent.pdf",       # необязательно: локальный файл или URL
    url="https://oge.fipi.ru/",     # необязательно: внешняя ссылка
)
```

Меню, навигация и ежедневная рассылка строятся из этих данных автоматически —
ничего больше менять не нужно.

## Структура

```
oge_bot/
  config.py        — конфигурация из .env
  content.py       — учебные материалы (предметы → темы → материалы)
  shop.py          — сборники для продажи (предметы ОГЭ 2026 + цены)
  legal.py         — FAQ, контакты, оферта, политика конфиденциальности
  texts.py         — тексты сообщений
  keyboards.py     — инлайн-клавиатуры
  database.py      — SQLite: подписчики, позиция в ленте, карта relay
  services.py      — отправка материала (текст + файл + ссылка)
  scheduler.py     — ежедневная рассылка
  handlers/
    browse.py      — /start, навигация по предметам/темам, материал дня
    subscription.py — подписка/отписка
    shop.py        — магазин сборников (выбор, реквизиты, чек)
    info.py        — FAQ, контакты, соглашение, политика
    relay.py       — чат покупатель ⇄ админ магазина
  main.py          — точка входа
```
