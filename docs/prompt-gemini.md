# Промпт для Gemini: дизайн мини-приложения

Скопируй всё, что ниже разделителя, и вставь в Gemini одним сообщением.
Готовый `index.html` пришли мне — логику к нему подключу я.

---

Сделай мини-приложение Telegram — **один файл `index.html`**, внутри которого
вся вёрстка, стили и скрипты. Без React, без Vue, без Tailwind по ссылке, без
внешних шрифтов, библиотек и картинок: внутри Telegram они не загружаются.
Можно подключить только `<script src="https://telegram.org/js/telegram-web-app.js"></script>`.

Экран мобильный, ширина 390 px. Тема тёмная. Стиль — игровой, яркий,
неоновый, с градиентами и свечением; крупные кнопки под палец, скруглённые
карточки, плавные переходы. Приложение про Roblox, аудитория — подростки.

## Четыре экрана внутри одной страницы

Переключение — сменой видимой секции, без перезагрузки.

**Экран 1 — вход.**
Крупная иконка, заголовок «Сколько дней ты в Roblox?», короткое пояснение,
поле ввода «Твой ник в Roblox» и кнопка «Найти аккаунт». Пока идёт поиск —
состояние загрузки. Место под сообщение об ошибке (например, «Аккаунт с таким
ником не найден»).

**Экран 2 — результат.**
Сверху карточка профиля: круглый аватар, отображаемое имя, ник через собачку,
маленькая метка «✓ verified» или «аккаунт забанен».
Дальше — главный элемент экрана: **огромное число дней**, которое
**прокручивается как барабаны игрового автомата**: каждая цифра в своём
окошке крутится сверху вниз пару оборотов и останавливается на нужной,
соседние цифры с небольшой задержкой друг за другом. Под числом подпись
«дней в Roblox» и строкой ниже расшифровка «это 20 лет 5 месяцев».
Ниже — плитки со статистикой: дата регистрации, подписчики, друзья, User ID.
Внизу яркая кнопка «Получить 🎁» и неяркая «Другой ник».

**Экран 3 — спонсоры.**
Заголовок «Остался один шаг», полоса прогресса и подпись «Отмечено 3 из 27».
Список каналов: в строке слева иконка, посередине название, справа кнопка
**«Подписаться»**. По нажатию кнопка становится **неактивной серой с текстом
«Готово ✓»** и открывается ссылка канала. Список может быть любой длины —
рисуй его циклом по массиву. Внизу прилипшая к экрану кнопка «Проверить
подписку» и место под плашку «Подпишись, пожалуйста, на всех спонсоров».

**Экран 4 — готово.**
Зелёная галочка с эффектом появления, заголовок «Готово!», подпись
«Подписка подтверждена» и блок с текстом, который потом будет приходить с
сервера. Кнопка «Проверить другой ник» возвращает на экран 1.

## Как оформить код (это важно, чтобы я быстро подключил данные)

Вверху скрипта положи демо-данные и рисуй экраны из них — чтобы файл сразу
открывался и всё было видно:

```js
const DEMO_USER = {
  username: "builderman",
  display_name: "builderman",
  avatar_url: "",
  created: "2006-03-08T17:17:52Z",
  age: { years: 20, months: 5, days: 0, total_days: 7457 },
  age_text: "20 лет 5 месяцев",
  followers: 71307164,
  friends: 0,
  id: 156,
  is_banned: false,
  has_verified_badge: true
};

const DEMO_LINKS = [
  { title: "🛍️ Вб дарит бесплатно", url: "https://t.me/example1" },
  { title: "💅 Трендовый маник",    url: "https://t.me/example2" },
  { title: "😱 Рекко",              url: "https://t.me/example3" }
];
```

И сделай ровно такие функции, каждая только рисует, без запросов в сеть:

- `showScreen(name)` — где name это `start` / `result` / `sponsors` / `done`
- `renderResult(user)` — заполняет экран 2 из объекта, как `DEMO_USER`
- `renderSponsors(links)` — рисует список из массива, как `DEMO_LINKS`
- `setDone(text)` — подставляет текст на экране 4
- `showError(text)` — показывает плашку с ошибкой на экране 1
- `showCheckError(text)` — плашка «подпишись на всех» на экране 3

Кнопки пусть вызывают пустые заглушки `onSearch(nick)`, `onGet()`,
`onCheck()` — я подставлю в них настоящие запросы к серверу.

Всё, что выводится из данных, экранируй: в названиях каналов встречаются
`<` и `&`.

Пришли готовый файл целиком, одним куском кода.
